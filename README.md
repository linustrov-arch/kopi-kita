# Kopi Kita

Website coffee shop dengan katalog menu, pemesanan meja, dan CMS untuk
mengelola produk serta booking.

## Fitur

### Halaman Menu
Daftar produk kopi dan makanan beserta harga, deskripsi, dan foto.
Pengunjung bisa menelusuri menu tanpa perlu login.

### Booking Meja
Pengunjung memilih tanggal, jam, dan jumlah orang, lalu mengirim data
kontak. Sistem mencatat booking dan menampilkan ketersediaan meja.

### CMS
Halaman admin untuk mengelola isi website:
- Tambah, ubah, dan hapus produk menu
- Lihat dan ubah status booking yang masuk

## Menjalankan

```bash
npm install
npm run dev
```

Buka http://localhost:3000

## Teknologi

Next.js (App Router), TypeScript, Tailwind CSS.
